# 🎬 IMDB Movie Review Sentiment Analysis

## 📌 Project Overview

This project is a **Machine Learning based Sentiment Analysis System** that predicts whether an IMDB movie review is **Positive 😊** or **Negative 😔** using the **Naive Bayes Algorithm**.

The project uses Natural Language Processing (NLP) techniques for text cleaning and preprocessing before training the model.

---

# 🚀 Features

* Clean and preprocess movie review text
* Remove HTML tags, URLs, punctuation, and stopwords
* Perform stemming using Porter Stemmer
* Convert text into machine-readable format
* Train model using Naive Bayes Algorithm
* Predict review sentiment (Positive / Negative)

# ⚙️ Project Workflow

1. Import Dataset
2. Clean Text Data
3. Remove Stopwords
4. Apply Stemming
5. Encode Labels
6. Convert Text using Vectorization
7. Train Naive Bayes Model
8. Test Model Accuracy
9. Predict Sentiment
